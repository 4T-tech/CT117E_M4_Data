# CT117E_M4

四梯嵌入式竞赛实训平台（MCU型号为STM32G431RBT6） 资料包

## 文件结构

- [1]例程_四梯教研编：四梯教研编写的CT117E硬件平台的例程

  - HAL库例程
  - LL库例程

- [2]例程_嵌入式设计与开发实训指导书：嵌入式设计与开发实训指导书配套例程

  - HAL库例程
  - LL库例程

- [3]开发环境及辅助工具

  - 串口调试助手
  - STM32_CUBE_MX下载地址：https://www.st.com.cn/zh/development-tools/stm32cubemx.html#get-software
  - 双击下载MDK.url：双击该文件，即可前往官网下载MDK开发环境
  - MDK-ARM下载地址：https://www.keil.com/demo/eval/arm.htm#/DOWNLOAD
  - Keil.STM32G4xx_DFP.1.2.0.pack、Keil.STM32G4xx_DFP.2.0.0.pack：STM32G4芯片包
  - PDF阅读器
  - ARMCC：AC5编译器
  - ReadMe.txt：CT117E竞赛平台硬件版本说明

- [4]硬件平台相关资料

  - 相关芯片手册：CT117E硬件平台上相关芯片手册大全
  - CT117E_M4_UM：蓝桥杯单片机设计与开发竞赛实训平台用户手册
  - SCH_CT117E_M4_V1.1、SCH_CT117E_M4_V1.2：CT117E硬件平台原理图

- [5]USB驱动：USB驱动_CT17E开发板与PC连接时的USB端口驱动

  - CMSIS-DAP_Update.INF：驱动程序
  - Readme.txt：驱动程序安装说明

- [6]测试文件

  - CT117E-M4_test.hex：CT117E测试程序
  - 测试流程说明_CT117E：测试流程说明
